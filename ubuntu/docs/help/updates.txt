--------------------------------------------------------------------------------
Mensaje al login (MOTD)
--------------------------------------------------------------------------------

  «mantenimiento de seguridad expandido para Applications desactivado»
  «actualizaciones… con ESM Apps»

  Eso es Ubuntu Pro / ESM (Canonical), OPCIONAL y de pago/gratis con límites.
  NO significa que unattended-upgrades esté mal.

  Capa gratis (este kit):
    unattended-upgrades → solo -security del archivo Ubuntu, cada día.

  Capa Pro (opcional):
    sudo pro attach <token>   # https://ubuntu.com/pro

--------------------------------------------------------------------------------
Qué hace el menú
--------------------------------------------------------------------------------

  2) Activa Update-Package-Lists + Unattended-Upgrade diarios
  3) Muestra si el servicio está activo y si hay parches pendientes
  5) Aplica seguridad ahora (sin esperar al cron)
  6) Cron de apt upgrade COMPLETO (todos los paquetes; más agresivo)
  8) Reinicio automático si un parche de kernel lo pide (off por defecto)

Archivos:
  /etc/apt/apt.conf.d/20auto-upgrades
  /etc/apt/apt.conf.d/50unattended-upgrades
  /var/log/unattended-upgrades/unattended-upgrades.log
